# أدواتك الذكية — الإصدار الثاني

موقع عربي ثابت جاهز للاستضافة المجانية على GitHub Pages.

## النشر
1. فك الضغط عن ملف ZIP.
2. افتح مستودع `mazooniosman299-blip/adawatak-site` على GitHub.
3. اختر Add file → Upload files وارفع **محتويات** مجلد `adawatak-v2` مباشرة إلى جذر المستودع، بما فيها مجلد `assets` (وليس ملف ZIP ولا المجلد الأب).
4. وافق على استبدال `index.html` القديم ثم اضغط Commit changes.
5. انتظر دقائق وافتح https://mazooniosman299-blip.github.io/adawatak-site/ .

## ما الذي يتضمنه؟
7 أدوات وصفحات من نحن والخصوصية والشروط والتواصل، إضافة إلى وصف SEO وملفي robots.txt وsitemap.xml.

## ملاحظات
- تتطلب أدوات QR وPDF اتصالًا بالإنترنت لتنزيل مكتبات JavaScript الخارجية.
- صفحات الخصوصية والشروط نماذج أولية يجب مراجعتها عند إضافة إعلانات أو أدوات تتبع.
- ليس هناك إعلانات مفعلة ولا ضمان للموافقة على AdSense.
- لا يوجد خادم أو قاعدة بيانات أو حسابات مستخدمين.
